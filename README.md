## Project Concept

**Fried Chicken Delivery** is a web application for ordering fried chicken online, featuring customizable box sets that allow customers to personalize their meals.

The main objective of this project is to demonstrate the practical application of **Object-Oriented Programming (OOP)** principles in a real system.

Before developing the web application, the system was designed and analyzed using software engineering diagrams, including:

* **Use Case Diagram** — to identify system functionalities and user interactions
* **Class Diagram** — to design classes, attributes, methods, and relationships
* **Sequence Diagram** — to describe interactions between objects throughout each process

After completing the system design, the concepts were implemented as a **web application demo using Python and FastHTML**.

## 🎯 Project Objectives

* Apply Object-Oriented Programming concepts to a practical application
* Practice system analysis and design before implementation
* Design relationships between objects using UML diagrams
* Develop a functional web application based on the designed system
* Demonstrate how OOP concepts can be applied to a real-world ordering system

## Features

### Customer

* Browse fried chicken and menu items
* Select food and box sets
* Add items to basket
* Increase / decrease item quantities
* Remove items from basket
* Place orders
* View order information

### Manager

* Manage menu items
* Manage box sets
* Manage orders

## 🧩 OOP Concepts

The project focuses on applying the fundamental concepts of Object-Oriented Programming:

* **Encapsulation**
* **Inheritance**
* **Polymorphism**
* **Abstraction**
* **Composition and object relationships**

The system was designed using UML diagrams before implementation to ensure that the classes and their relationships correspond to the requirements of the application.

## System Design

### Use Case Diagram

The Use Case Diagram describes the interactions between customers, managers, and the ordering system.

### Class Diagram

The Class Diagram defines the structure of the system, including classes, attributes, methods, inheritance, and relationships between objects.

### Sequence Diagram

The Sequence Diagram illustrates how objects communicate with each other during important processes such as ordering food and managing the basket.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Sky92-dev/Object-Oriented-Project-2024
```

### 2. Install dependencies

```bash
pip install python-fasthtml
pip install uvicorn
```

### 3. Start the FastHTML application

```bash
uvicorn main:app --reload --port 5001
```

### 4. Open the Web App

http://localhost:5001
